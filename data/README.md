# Data

Datos crudos y procesados usados o generados por NidoSmart, separados de los documentos y modelos que los interpretan.

* `external/` — conjuntos de datos de terceros o públicos (por ejemplo, series de precios del huevo, datos climáticos regionales) usados como insumo de análisis o modelos.
* `experimental/` — datos generados por experimentos o el piloto propio de NidoSmart (por ejemplo, lecturas de sensores, registros de producción).

Este directorio contiene los datos en sí, no su análisis: las conclusiones derivadas de estos datos viven en [`research/`](../research/) o en [`models/`](../models/), según corresponda.
