# NidoSmart — Proyecto de inversión

Cómo se financia la primera unidad de NidoSmart. Mientras el [plan de negocios](../business-plan/README.md) describe cómo funcionará el negocio, este directorio describe la estructura financiera, la viabilidad y el expediente necesarios para conseguir financiamiento (por ejemplo, a través de FIRA/FONAGA).

## Documentos

1. [Proyecto de inversión](./01-proyecto-de-inversion.md)
2. [Estructura financiera](./02-estructura-financiera.md)
3. [Viabilidad financiera](./03-viabilidad-financiera.md)
4. [Impacto y expediente de financiamiento](./04-impacto-y-expediente-financiamiento.md)

## Fuentes que consume este documento

* Las cifras de inversión y proyecciones deben provenir de una fuente única en [`models/financial/`](../../models/) y [`models/production/`](../../models/), no de cálculos propios y potencialmente divergentes de los del plan de negocios.
* Las cotizaciones y demás evidencia que respalda cada cifra (por ejemplo, las cotizaciones de FamTECH) viven en [`evidence/quotations/`](../../evidence/quotations/) y [`evidence/financing/`](../../evidence/); este directorio las referencia, no las duplica.
* Los documentos de programas de financiamiento (FIRA, FONAGA, NAFIN, programas estatales de Puebla) viven en [`knowledge-base/financing/`](../../knowledge-base/financing/).

## Nota

Cualquier cifra de escala (por ejemplo, número de aves) usada aquí debe ser consistente con la usada en el [plan de negocios](../business-plan/README.md) y en los [modelos](../../models/). Si difieren, debe señalarse explícitamente en [`docs/governance/registro-de-decisiones.md`](../governance/registro-de-decisiones.md) hasta que se resuelva.
