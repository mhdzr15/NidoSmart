# NidoSmart — Innovación

Qué va a investigar y desarrollar NidoSmart, y por qué. Este directorio no es una biblioteca de referencias: contiene las **conclusiones propias de NidoSmart**, derivadas del análisis en [`research/`](../../research/) sobre las fuentes de [`knowledge-base/`](../../knowledge-base/).

Por ejemplo, [`02-estado-del-arte.md`](./02-estado-del-arte.md) no debe contener páginas copiadas de papers. Debe decir algo como:

> Ya existen sistemas comerciales para X. La literatura resuelve Y. Z todavía tiene limitaciones. Por lo tanto, NidoSmart adoptará X, adaptará Y e investigará Z.

## Relación con el resto del proyecto

* El [plan de negocios](../business-plan/README.md) dice cómo funciona el negocio; el [proyecto de inversión](../investment-project/README.md) dice cómo se financia la primera unidad; este directorio dice qué se va a investigar y desarrollar.
* Toda decisión estratégica que surja de aquí (por ejemplo, una línea de investigación o una política de propiedad intelectual) debe registrarse en [`docs/governance/registro-de-decisiones.md`](../governance/registro-de-decisiones.md).
* Investigar no implica publicar todo, y transferir tecnología no significa regalar propiedad intelectual: ningún resultado de I+D con posible valor comercial se divulga públicamente antes de una evaluación de propiedad intelectual (ver [Propiedad intelectual](./05-propiedad-intelectual.md)).
